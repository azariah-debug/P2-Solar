# P2 Solar

Static P2 Solar website with responsive layouts and nine content views.

## Publish on GitHub Pages

In the repository's **Settings → Pages**, choose **Deploy from a branch**, select **main** and **/(root)**, then save. No build step is needed.

The repository is `azariah-debug/P2-Solar`. The share metadata is configured for `https://azariah-debug.github.io/P2-Solar/`; publication must finish before that address is live.

## Edit

- `index.html`: homepage and sharing metadata
- `styles.css`: design and responsive layout
- `app.js`: page content and navigation
- `p2-solar-hero-v2.jpg`: hero and social-preview image

Run `python3 -m http.server 4176` in this directory to preview locally.

Project entries, news, and contact pathways still need the corresponding project details, announcements, and contact information before a final public launch. No contact form or email delivery is configured.
